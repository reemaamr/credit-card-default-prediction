# Credit Card Default Prediction

This project aims to predict whether a credit card customer will default on their payment using machine learning.

## Dataset

UCI Default of Credit Card Clients Dataset.

A balanced sample of 1,500 records was used.

## Machine Learning Models

* Logistic Regression
* Support Vector Machine (SVM)

## Project Steps

1. Data loading and exploration
2. Data preprocessing
3. Feature engineering
4. Model training
5. Hyperparameter tuning
6. Model evaluation and comparison
7. Single-customer prediction

## Tools

Python, Pandas, Scikit-learn, Matplotlib, and Seaborn.

## Purpose

A machine learning project developed for educational purposes.
